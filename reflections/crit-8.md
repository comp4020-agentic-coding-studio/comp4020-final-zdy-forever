# Crit 8 — It's alive

**The breakthrough.** The missing YouTube Data API key initially looked like an obstacle to my shared-listening idea. I accepted an alternative: users paste links, the application retrieves metadata through official oEmbed, and videos play through the visible IFrame Player. The change is recorded in [`e866195`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-zdy-forever/commit/e866195).

This narrowed the product, but preserved what mattered to me: friends contributing media and spending time together. Search was convenient rather than essential. Avoiding a Data API key also removed that particular credential from the application; it did not make the whole repository automatically safe to publish.

The same distinction matters for the visual design. I wanted the playful feeling of a party game, while CLAUDE.md prohibits copying Eggy Party characters, logos, assets or exact screens. A design reference can guide an atmosphere without becoming a source of copied assets. That instruction is a constraint to check, not proof that every public-release concern has been resolved.

**What this changed.** My role felt less like implementing every requested feature and more like deciding which compromises preserved the intended experience. I used Claude Code to implement the system, but choosing to keep shared viewing and drop search was a product decision I accepted. I want to make those boundaries clear before asking an agent to expand the application. This lesson comes from my development and self-testing; the crit presentation was not a peer discussion that produced this decision.
